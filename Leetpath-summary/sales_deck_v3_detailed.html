03. Engineering Architecture

Enterprise-Grade Implementation

A decoupled, high-performance stack designed for security and scalability.

⚡ Frontend Strategy

Vanilla JS/HTML/CSS: Chosen over frameworks to achieve ultra-low TTI. Result: Seamless single-page experience with zero bundle bloat.

🔒 Security Architecture

Auth: Google OAuth 2.0 via Passport.js.
Tokens: JWTs stored in HttpOnly Cookies to mitigate XSS.

🛡️ Infrastructure Protection

Helmet.js: Securing HTTP headers.
Express-Rate-Limit: Preventing API abuse and DoS attacks on the backend.

🌐 Cloud Orchestration

Vercel (Edge): Optimized frontend delivery.
Render (Cloud): Scalable Node.js environment with split-origin CORS management.
